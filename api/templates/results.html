What these numbers don't hide

Diagrams are weaker than the baseline. Figure descriptions weren't ingested, so wiring-diagram labels are missing from our passages. With 6 diagram questions this is a one-question difference.
Keyword search alone scores higher on tables than the fused method. Semantic search pulls some table rows down, and the fused method still beats the baseline.
Three questions can't be answered by any method yet. They're about the scanned manual, which needs OCR. Every row shares that ceiling equally.
Small sample. With {{ results.n.OVERALL }} questions, one question moves a column by 0.14–0.17. Read these as directional, not statistically significant.
